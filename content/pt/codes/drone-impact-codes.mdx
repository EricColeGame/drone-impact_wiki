## Como Resgatar Códigos de Drone Impact Passo a Passo

Resgatar recompensas é simples, embora a localização exata dos menus possa variar um pouco dependendo da plataforma utilizada. Siga este passo a passo para reivindicar seus itens rapidamente.

```
[Tela do Lobby Principal] ➔ [Avatar / Menu de Configurações] ➔ [Aba Resgatar Código] ➔ [Inserir Código] ➔ [Coletar no Correio do Jogo]
```

| :--- | :--- | :--- | :--- |
| **Menu de Configurações no Jogo** | Avatar do Perfil ➔ Configurações ➔ Código de Presente | Instantâneo (Correio Direto) | Jogadores de Mobile e Console |

### Instruções Detalhadas no Jogo

1. Inicie o jogo e carregue a tela do lobby principal do comandante.
2. Conclua a missão do tutorial inicial se estiver jogando em uma conta nova.
3. Toque no **Avatar do Perfil do Comandante** localizado no canto superior esquerdo.
4. Selecione o menu de **Configurações** (ícone de engrenagem) e navegue até a aba **Conta / Serviço**.
5. Toque no botão **Resgatar Código** para abrir a caixa de diálogo de texto.
6. Digite ou cole um dos **códigos de Drone Impact** ativos na caixa.
7. Clique em **Confirmar** ou **Trocar** e, em seguida, verifique sua caixa de correio no jogo para coletar suas recompensas.

Para estratégias adicionais de recompensas em jogos, análises de atualizações e novidades de transmissões, confira a cobertura completa nos [guias de jogos da Polygon](https://www.polygon.com/).

## Solução de Problemas: Por Que Meus Códigos de Drone Impact Não Estão Funcionando?

Se um código não funcionar, vários fatores comuns podem ser os responsáveis. Revise a lista de verificação abaixo para identificar o problema antes de entrar em contato com o suporte ao cliente.

| Mensagem de Erro / Sintoma | Causa Principal | Solução Recomendada |
| :--- | :--- | :--- |
| **"Código Expirado"** | O período promocional do desenvolvedor terminou | Descarte o código e use vouchers ativos mais recentes |
| **"Código Inválido / Não Encontrado"** | Erro de digitação ou diferença entre maiúsculas e minúsculas | Copie e cole o código diretamente, sem espaços extras |
| **"Já Resgatado"** | O código já foi reivindicado anteriormente no ID da sua conta | Verifique o histórico da caixa de correio; os códigos são de uso único por servidor |
| **"Nível de Conta Insuficiente"** | Alguns códigos exigem níveis mínimos de progressão | Avance pelas fases do prólogo para desbloquear os requisitos de nível |
| **"Região de Servidor Incompatível"** | O código é restrito a servidores regionais específicos (ex.: NA/EU/Ásia) | Verifique a localização do seu servidor atual nas configurações da conta |

Os **códigos de Drone Impact** são combinações de texto promocionais especiais lançadas pelos desenvolvedores do jogo.
