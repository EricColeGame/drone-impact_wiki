## Step-by-Step Flight Planning to Prevent Incursions

To maintain complete safety and avoid federal investigation, pilots should adopt a systematic pre-flight workflow. Incorporating these verified procedures guarantees that every operation aligns with the guidance provided in the **Drone Impact release**.

### Phase 1: Airspace Reconnaissance
1. Open an FAA-approved LAANC provider (e.g., Aloft, AutoPylot, AirMap).
2. Check for active Temporary Flight Restrictions (TFRs), VIP movement corridors, and military training routes.
3. Review surrounding terrain and confirm distances from sensitive facilities (minimum 3–5 nautical miles recommended from military perimeters).

### Phase 2: Hardware Health and Remote ID Check
1. Confirm FAA registration numbers are clearly visible on the drone exterior.
2. Verify Remote ID broadcast status before launching props.
3. Update geofencing firmware to ensure flight boundaries are mechanically enforced.

### Phase 3: In-Flight Monitoring and Contingencies
1. Maintain continuous Visual Line-of-Sight (VLOS).
2. Monitor battery levels to guarantee return-to-home (RTH) failsafes activate well above reserve thresholds.
3. Terminate flight immediately if manned aircraft or emergency helicopters enter the local airspace.

| Flight Phase | Primary Risk | Preventative Measure |
| :--- | :--- | :--- |
| **Pre-Takeoff** | Outdated airspace maps | Refresh LAANC provider cache via cellular data |
| **Ascent** | Entering controlled Class C/D shelf | Set altitude limiters in ground station software |
| **Mid-Mission** | Unintentional drift into R-Zone | Program hard GPS geofencing boundaries |
| **Emergency / Failsafe** | Flyaway toward restricted facility | Pre-set RTH landing point away from restricted borders |
